# QR Code Check-In System

A web-based QR check-in interface integrated with Power Apps and Power Automate for real-world event management.

Built to handle attendee validation and streamline check-in processes using QR codes.

## Features

- QR code-based attendee check-in
- Real-time validation against backend data
- Web interface for scanning and status display
- Integration with Power Apps and Power Automate
- Automated attendee tracking and updates

## Tech Stack

- HTML / JavaScript
- Power Apps
- Power Automate
- Dataverse (backend)

## How It Works

1. Users register and receive a unique QR code
2. QR code is scanned via the web interface
3. System validates the QR against stored attendee data
4. Status is updated (checked-in / invalid)

## What I Built

- Web interface for QR scanning and result display
- Integration with backend automation flows
- Data validation logic for attendee records
- End-to-end check-in workflow

## Notes

This system was built for internal company use and is part of a larger event registration and attendance tracking solution.
